# CTC API
Description: Add/change a backend API safely.

Steps:
1. Find the route and frontend consumer.
2. Inspect auth and validation middleware.
3. Define request/response contract.
4. Validate input.
5. Enforce RBAC and ownership.
6. Update frontend service/types/cache/realtime if needed.
7. Add success, validation-failure and authorization-failure tests.
8. Run backend tests and frontend build if both changed.
