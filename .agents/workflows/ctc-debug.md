# CTC Debug
Description: Reproduce and fix a CTC Task bug by root cause.

Steps:
1. Reproduce the issue.
2. Capture exact error/behavior.
3. Trace the call path.
4. Search for related implementations.
5. Identify the root cause.
6. Add/update a regression test.
7. Apply the smallest fix.
8. Run focused and relevant broader checks.
9. Review the diff.
