# CTC Plan
Description: Create a reviewable implementation plan before coding.

Steps:
1. Inspect the repository; do not guess.
2. Identify affected files/modules.
3. Trace frontend → backend → database/realtime flow when applicable.
4. Identify RBAC/security risks.
5. Identify migration/config impact.
6. Propose the smallest implementation.
7. Define tests and verification.
8. Do not edit code until the plan is reviewed.
