# CTC Security
Description: Focused security audit.

Steps:
1. Inspect current diff and relevant surrounding code.
2. Check auth/RBAC/IDOR.
3. Check injection/XSS/unsafe HTML.
4. Check uploads/path traversal.
5. Check secrets and credential exposure.
6. Check mail/AI boundaries.
7. Check admin/destructive operations.
8. Check rate-limit abuse.
9. Report only evidence-backed findings with severity and remediation.
10. Never print secret values.
